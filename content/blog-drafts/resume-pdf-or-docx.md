It's a small decision that causes a surprising amount of worry. The rule is simple.

## The order of priority

1. **If the employer specifies a format, use it.**
2. **Otherwise, send a text-based PDF.** It looks the same on any device.
3. **Use DOCX** when asked, or when an agency recruiter needs to edit it.

## What to check about your PDF

Not all PDFs are equal. A PDF exported from Word or Google Docs holds real text. A scanned page or an image-based design may not be readable by software.

Do this quick test: open the PDF, select all the text, copy it and paste it into a plain text note. If it comes out garbled, in the wrong order, or not at all, the software reading your application may have the same trouble.

## File name

Use something a recruiter can find: `Asha-Rao-Resume.pdf`, not `final_v7_NEW.pdf`.

## Keep the file small

A resume with no large images should be small. Some forms set upload limits, and Iris accepts PDF and DOCX up to 5 MB during setup.

## Keep your source file

Save an editable master, which makes tailoring much easier. PDF is for sending, and your source document is for changing.

## How Iris uses your file

When you upload a resume, Iris reads it and fills in your profile, so you can review the details rather than type them. Check the result, because parsing isn't perfect on unusual layouts. A simple format helps, as explained in [ATS resume myths](/blog/ats-resume-myths/).

## Frequently asked questions

### Do applicant tracking systems read PDFs?

Most modern systems handle text-based PDFs well, though results vary by system and layout. If you have any doubts, follow the form's guidance.

### Should I use a Canva template?

Design tools can produce files that look good but parse poorly, so run the copy-and-paste test. Plain layouts are the safer option for most roles.
